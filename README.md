
# 🍫 North America Wonka Bar Chocolate Sales Analysis (2020–2024)

## 📌 Project Overview
This repository contains a comprehensive **business intelligence dashboard** analyzing Wonka Bar chocolate sales across North America (2020–2024).  
The dashboard highlights **key metrics, trends, and actionable insights** to support strategic decision-making in production, marketing, and logistics.

---

## 🎯 Objectives
The analysis focuses on six core goals:
1. Identify top-selling chocolate products driving order volumes.
2. Compare profitability across regions to highlight strong and weak markets.
3. Analyze shipping mode distribution (Standard Class dominance).
4. Track profit growth trends over multiple years.
5. Compare monthly order values to identify peak and declining periods.
6. Pinpoint top-performing cities for targeted campaigns and expansion.

---

## 📊 Data Source
- **Dataset Provider:** Maven Analytics  
- **Timeline:** 2020–2024  
- **Size:** 10,000+ rows, 18 columns  

---

## 🛠 Tools Used
- **Excel** (data preprocessing, cleaning)  
- **Power BI** (Power Query, data modeling, visualization)  

---

## 🔄 Data Preprocessing
- Filled missing values  
- Removed duplicates  
- Standardized text (TRIM, PROPER)  
- Sorted values for structured analysis  
- Validated totals for accuracy  

---

## 🧩 Data Modeling
- Created a **Calendar Table** for time intelligence functions.  
- Established **one-to-many relationships** between Orders and Calendar tables.  
- Defined core measures:  
  - `Total Orders`  
  - `Total Sales Amount`  
  - `Total Profit`

## 🔑 Key Insights
- **Products:** Milk Chocolate dominates; mid-range items show moderate traction; weaker products need repositioning.  
- **Regions:** Pacific leads in profit; Gulf lags significantly.  
- **Shipment Modes:** Standard Class (~60%) is preferred; Same Day (~5%) adoption is weak.  
- **Yearly Trends:** Profits stable (2021–2022), sharp rise in 2023–2024.  
- **Seasonality:** November & December are peak months; May is weakest.  
- **Cities:** New York leads with ~1000 orders; Los Angeles & Philadelphia follow.  

---

## 📌 Conclusion
The business achieved **$93.4K profit** with steady growth from 2021–2024.  
- **Top performers:** Milk Chocolate, Pacific region, New York City  
- **Seasonal peaks:** November & December  
- **Preferred shipping:** Standard Class  

**Strategic Recommendations:**  
- Sustain top performers  
- Strengthen mid-tier regions/products  
- Uplift weaker cities and shipment modes for balanced expansion
